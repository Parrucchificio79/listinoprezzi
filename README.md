# Parrucchificio 79 · Listino prezzi

Sito del listino di Parrucchificio 79, parrucchiere ed estetica a Cantù (CO).

- `index.html`: tutta la pagina (prezzi, promo, orari, contatti)
- `promo-*.jpg`: i volantini del carosello promo
- `logo.jpg`: logo

Per cambiare un prezzo: apri `index.html`, cerca il servizio (es. "Piega corta") e modifica il numero accanto. Il sito si aggiorna da solo in un paio di minuti.
